1. Introduction                                              *mtoc-introduction*

mtoc.nvim opens a floating Table of Contents for the current
markdown or LaTeX buffer, letting you jump to any heading, and collapse or
expand sections using Neovim's native folding -- rendered in a clean,
Word/Acrobat-style outline (arrow indicators, no line-count clutter).

==============================================================================
2. Setup                                                            *mtoc-setup*

Call the setup function once, typically from your plugin manager's config: >lua
    require("mtoc").setup()
<
`setup()` may be called with no arguments to use the defaults, or with a
table overriding any subset of options (see |mtoc-configuration|).

==============================================================================
3. Usage                                                            *mtoc-usage*

By default, pressing `<leader>tc` in a `markdown` or `tex` buffer opens the
TOC in a floating window. You can also call it manually: >lua
    require("mtoc").open()
<
Inside the TOC window:

  <CR>          Jump to the heading under the cursor, and close the TOC.
  q / <Esc>     Close the TOC.
  zc / za       Fold/toggle the heading under the cursor (or, if it has no
                children, its nearest foldable ancestor).
  zC / zA       Same, recursively (all nested levels).
  zR / zM       Open/close all folds (native Vim commands, work as usual).

==============================================================================
4. Configuration                                            *mtoc-configuration*

Defaults, and the options table structure: >lua
    require("mtoc").setup({
      filetypes = { "markdown", "tex" },
      keymap = "<leader>tc",
      width = 0.8,
      height = 0.7,
      levels = {
        [1] = { fg = "#2563eb", bold = true },
        [2] = { fg = "#16a34a", bold = false },
        [3] = { fg = "#d97706", bold = false },
      },
      fallback_hl = { fg = "#2563eb", bold = false },
      arrow = {
        enabled = true,
        open_char = "▾",
        closed_char = "▸",
        hl = { fg = "#94a3b8", bold = false },
      },
    })
<
See README.md for a description of each field.

==============================================================================
5. Folding behavior                                                *mtoc-folding*

The TOC uses Neovim's native `foldexpr` folding rather than a custom tree
widget, so it stays lightweight. Some notable behaviors:

- Every heading with children can be folded, at any level (H1 through H6).
- Same-level sibling headings never accidentally merge into one fold.
- Headings with no children cannot be independently folded; invoking a fold
  command on one instead folds its nearest ancestor with children.
- Fold (collapsed/expanded) state is remembered per source buffer for as
  long as Neovim stays open, and restored the next time the TOC is reopened.
  It is NOT persisted to disk, and resets when Neovim quits.
